## 归档纪律

1. **进来不改**：归档文件视为快照。发现事实错误，在文件头加一行 `> 更正见 xxx`，
   不要直接改正文——否则就失去了"当时怎么想的"这个价值。
2. **旧路径保留**：部分归档文件里的路径是当年的（`bin/`、`drivers/580.178.04/`），
   现在已改成 `check/`、`patches/`。**故意不改**，因为改了就不是当时的记录了。
   文件头已加注说明对应关系。
3. **脱敏**：入库前必须去掉用户名、主机名、内网 IP、凭据、绝对家目录路径。
4. **大文件不入库**：`.ko`、`.o`、编译缓存等由 `.gitignore` 排除，
   需要时看 `ko-local-说明.md` 里的版本信息自行复现。

## 与 docs/ 的分工

| 目录 | 性质 | 会更新吗 |
|---|---|---|
| `docs/` | **规范与速查**（怎么用、出问题怎么办、寄存器表） | 会，跟着实现走 |
| `history/` | **过程与决策**（为什么这样、当时错在哪） | 不会，只追加 |
