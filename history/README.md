## 怎么用这份归档

### 只想了解"怎么解锁"
看交付包的 `../README.md`，不用看这里。

### 想知道"为什么这么做、走过哪些弯路"
按上表读 `reports/`，重点是 **198 → 199** 这两篇。

### 想复现当年的实验
`pcie-gen2/tools/` 里有 49 个脚本。注意：

- 部分脚本硬编码了 `/data/labs/nvidia/pcie-gen2` 路径，搬走后要改
- 交付包的 `../bin/` 是同一批工具的**路径自包含版本**，优先用那个
- 早期脚本（`gen2-full.py` / `early-gen2.py` / `fight-probe.py` 等）是
  "用户态 mmap 写 BAR0"路线，**已被证明会 2/2 打挂设备**（reports/197），
  只作历史参考，不要在生产机上跑

### 想找回某个寄存器值 / 偏移
`../docs/寄存器参考.md`（整理过的）优先于这里的原始日志。
